## Design System Reference

| Token | Value |
|---|---|
| Corner radii | Cards: 16dp · Hero sections: 24dp · Chips: 20dp (fully round) |
| Border | 0.75dp, `BorderSubtle` / `SlateBorder` at 15–20% opacity |
| Phase glow alpha | 0.35f via `accentForPhase(phase, colors)` |
| Surface levels | `SlateSurface` → `SlateSurfaceAlt` → `SurfaceCard` → `SurfaceElevated` |
| Text hierarchy | `TextPrimary` (titles) · `TextSecondary` (labels) · `TextTertiary` (captions) |
| Accent per phase | Mint=Peak · Amber=Moderate · Coral=Rest (use `accentForPhase`) |
